# Space Invaders (C++17 / SFML)

Классический аркадный шутер, реализованный с нуля на C++17 с использованием SFML.

## Стек
- C++17, SFML 2.6
- CMake 3.x
- Платформа: Linux / Windows

## Возможности
- Движение игрока и стрельба
- Волны врагов с нарастающей скоростью
- Система очков и жизней
- Коллизии через AABB

## Сборка
```bash
mkdir build && cd build
cmake ..
make
./space_invaders
```
